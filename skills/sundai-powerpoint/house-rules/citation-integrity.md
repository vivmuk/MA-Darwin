# House rules — `citation-integrity`

Rules here override the defaults in `skills/citation-integrity/SKILL.md`.
See [README.md](README.md) for how to write a good one.

## Seeded examples

- Use Vancouver style, not AMA. Our target journals require it.
- Data on file citations must name the internal document number and the data
  owner, so a reviewer can actually retrieve it.
- Every reference in an externally facing document must be independently
  verified by a second person before release. The agent verification is a
  pre-check, not the control.
